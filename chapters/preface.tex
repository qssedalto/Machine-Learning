\section{阅读说明：这份笔记怎样使用？}\label{sec:introduction}

这份机器学习笔记从可手算的例子出发：先观察数据和预测，再引入损失函数、参数估计与迭代算法，最后讨论模型在新数据上的表现。每当出现抽象公式，先解释符号，再用具体数值计算，最后才写一般形式。这样可以把统计学、数学分析和 Python 实践连接起来。

第一课以西瓜分类与学习时间预测为例，认识样本、特征、标记、模型、参数和损失；第二课从四组数据推导线性回归的最小二乘解；第三课从 $f(x)=(x-3)^2$ 学会梯度下降，再训练两个参数；第四课使用 Sigmoid、伯努利似然和交叉熵构造二分类模型；第五课比较训练误差、测试误差和泛化误差，学习交叉验证、数据泄漏和分类指标。

\textbf{阅读建议：}第一次阅读重点看每节的“为什么”和手工算例；第二次自己推一遍公式、核对样本表格；第三次运行配套 Python 脚本。标有“选读”的矩阵公式或优化边界可以暂时跳过，不影响掌握前五课的主线。

资料主要参考周志华《机器学习》、李航《统计学习方法（第2版）》、James 等人的 \textit{An Introduction to Statistical Learning: With Applications in Python} 和基础最优化教材\cite{zhou2016,lihang2019,james2023,liu2020}。
