\section{阅读指南}\label{sec:introduction}

这份机器学习笔记从问题背景、数学定义和模型假设出发，介绍损失函数、参数估计、优化算法及泛化性能，并通过配套 Python 数值实验联系理论与实践。

前五课依次介绍机器学习基础、线性回归与最小二乘、梯度下降、逻辑回归以及模型评价与泛化。

\textbf{阅读建议：}重点理解模型假设、公式推导、优化目标与适用条件，并结合配套 Python 脚本开展数值实验。

资料主要参考周志华《机器学习》、李航《统计学习方法（第2版）》、James 等人的 \textit{An Introduction to Statistical Learning: With Applications in Python} 和基础最优化教材\cite{zhou2016,lihang2019,james2023,liu2020}。
